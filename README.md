# Resume Studio V2.5

一个基于 React + Vite 的可视化简历编辑器 Demo。

## V2.5 本次更新

- 模板结构从 12 种扩展为 **42 种真正不同的排版结构**。
- 新增 ATS、商务、现代、科技、时间轴、作品集、创意等分类。
- 模板库支持分类筛选和名称搜索。
- 模板库改为**悬浮面板**，展开时不会把 A4 简历往下顶。
- 点击模板立即切换并自动收起，简历内容不会被删除。
- 模板负责结构，右侧主题颜色保持独立；切换模板不会强制重置主题颜色。
- 保留 V2.2 的技能胶囊、模块图标选择、姓名/头像 X/Y 定位、自动保存、撤销/重做、PNG/PDF 导出。

## 运行

```bash
npm install
npm run dev
```

> 本 ZIP 不包含 node_modules，请在本机安装依赖后运行。


## V2.5 商业化定位说明
- 面向电脑端毕业生、应届生、实习求职者使用。
- 提供 42 种大众化简历排版结构，模板结构与主题颜色分离。
- 模块库提供常用、求职、校园、专业、能力等分类，并提供大量现成 Lucide 图标。
- 默认不接入付费系统，不要求用户注册或 API Key，适合个体户以 ZIP/网盘方式交付。
- 网站底部版权信息使用通用版权声明；ICP备案/公安备案等编号只有在实际取得后再填写，不使用虚构备案号。


## V2.5 编辑能力增强
- 姓名与照片支持 A4 画布实时拖动定位，以及 X/Y 精确定位。
- 照片尺寸输入直接作用于画布，不再限制 180px。
- 个人信息支持无限自定义字段。
- 教育、工作、项目、技能、荣誉及其他模块支持添加、复制、删除。
- 新增全屏沉浸式预览。
- 主题中心升级为多套设计主题 + 自定义主题色 + 视觉预览。
- 编辑缩放最高支持 125%。


## V2.5.2 PNG 导出修复
- PNG 导出改为独立固定 794×1123 A4 渲染层，完全脱离编辑器缩放。
- 导出时隐藏选中框、姓名/照片定位辅助线和编辑状态。
- 导出使用 3× 高清渲染，目标尺寸约 2382×3369 像素。
- 修正标准 ATS 模板对姓名/照片定位参数的传递。


## V2.5.3 更新
- PNG 导出直接截取当前预览区的真实 A4 DOM，预览与 PNG 使用同一套布局。
- 仅姓名和照片支持 X/Y 定位；其他简历模块保持模板固定布局，不支持画布自由拖动。
- 导出时隐藏选中边框等编辑态视觉元素，但不改变简历内容与布局。
- 不启用自动保存，继续使用手动保存/恢复。
